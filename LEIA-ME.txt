JL CERNE - SITE INSTALAVEL
==========================

Esta pasta e o app pronto para ir ao ar. Faltam 5 passos, todos seus,
porque dependem de contas no seu nome. Os nomes dos botoes podem variar
um pouco conforme o Firebase e o Netlify atualizam as telas.

Enquanto o passo 4 nao for feito, o app abre em "modo demonstracao":
funciona, mas nao salva nada.

PASSO 1 - Criar o projeto (Firebase, gratuito, sem cartao)
  1. Entre em https://console.firebase.google.com com uma conta Google.
  2. "Criar um projeto". Nome: jl-cerne. Pode desligar o Google Analytics.

PASSO 2 - Criar os logins
  1. Menu "Criacao" > "Authentication" > "Vamos comecar".
  2. Em "Metodo de login", ative "E-mail/senha".
  3. Aba "Usuarios" > "Adicionar usuario". Crie um para cada pessoa
     (Hanna, Joy e Lan), com e-mail e senha.

PASSO 3 - Criar o banco de dados
  1. Menu "Criacao" > "Firestore Database" > "Criar banco de dados".
  2. Local: southamerica-east1 (Sao Paulo). Modo: producao.
  3. Aba "Regras": apague o que estiver la, cole o texto abaixo e
     clique em "Publicar". Ele so deixa entrar quem fez login.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

PASSO 4 - Ligar o app ao projeto
  1. Engrenagem > "Configuracoes do projeto" > "Seus apps" > icone Web (</>).
  2. Apelido: JL Cerne. Registre. Nao precisa marcar "Hosting".
  3. Vai aparecer um bloco "firebaseConfig" com apiKey, authDomain etc.
  4. Abra o arquivo config.js desta pasta no Bloco de Notas e troque os
     valores pelos do seu bloco. Salve.
     (Se preferir, mande o bloco para o Claude e ele devolve a pasta pronta.)

PASSO 5 - Colocar no ar (Netlify)
  1. Entre em https://app.netlify.com/drop
  2. Arraste a pasta jl-cerne inteira para a pagina.
  3. Crie a conta quando ele pedir, senao o site e apagado em pouco tempo.
  4. Voce recebe um endereco terminado em netlify.app. Da para trocar o
     nome em "Site configuration" > "Change site name".

INSTALAR NO CELULAR
  Android (Chrome): abra o endereco > menu de tres pontinhos >
    "Instalar app" ou "Adicionar a tela inicial".
  iPhone (Safari): abra o endereco > botao de compartilhar >
    "Adicionar a Tela de Inicio".

SE O LOGIN NAO FUNCIONAR NO ENDERECO NOVO
  Firebase > Authentication > Configuracoes > "Dominios autorizados" >
  adicione o endereco netlify.app.

PARA ATUALIZAR O APP DEPOIS
  No Netlify, abra o site > "Deploys" e arraste a pasta nova.
  Os dados nao se perdem: eles ficam no Firebase, nao na pasta.
